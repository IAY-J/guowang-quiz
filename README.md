# 国网通信类刷题

纯前端刷题网站，把 2026 通信类结课测试 165 题直接写入默认可编辑题库，支持分类练习、综合卷抽题、分类错题库和应用内编辑题库。

## 快速开始

```powershell
python -m http.server 8000
```

访问 `http://127.0.0.1:8000/`，在“选择练习模式”页面选择套题类型。题库数据直接嵌入页面（`bank-data.js`），打开后自动进入可编辑题库，不再依赖单独加载题库文件。

## 练习模式

| 模式 | 说明 |
| --- | --- |
| 综合卷 | 全部题型按重点比例从各分类题库抽题，显示综合单选、专业单选等板块 |
| 行测 | 言语、逻辑、数量、资料分析等单独套题 |
| 企业文化 | 企业文化、时政、能源战略等单独套题 |
| 通信原理 | 专业分类单独套题 |
| 光纤通信 | 专业分类单独套题 |
| 数据通信网 | 专业分类单独套题 |
| 交换及接入 | 专业分类单独套题 |
| 移动通信及其他业务 | 专业分类单独套题 |
| 会议电视 | 专业分类单独套题 |

分类练习中只显示“单选 / 多选 / 判断”和分值，不显示“综合单选”“专业单选”等板块字样；板块字样只在综合卷中出现。各题分值保持试卷原规则不变。

## 综合卷抽题比例

综合卷固定包含综合单选、综合多选和资料分析全部题目，专业单选、专业多选、专业判断按重点比例从分类题库抽取：

- 通信原理（含信号与系统）：权重 5，约占 25%-30%
- 数据通信网：权重 4，约占 20%-25%
- 光纤通信：权重 3，约占 15%-20%
- 移动通信及其他业务：权重 3，约占 15%-20%
- 交换及接入：权重 2
- 会议电视：权重 1，约占 5%

每次进入综合卷会重新随机抽题。

## 功能

- 单选和判断点击选项立即判分；多选勾选后点“确认答案”，全部选对才得分。
- 答对答错都在选项下方显示正确答案和解析。
- 每道题显示题号和分值，支持上一题 / 下一题、答题卡跳题、键盘数字键答题。
- 最后一题答完后显示“提交试卷”，交卷后显示总分、题型统计和本次错题。
- 错题库按分类长期保存在浏览器本地，可筛选分类、重练、导出和清空。
- 题目和选项支持图片（图片地址或 base64），导入题库和编辑题库时都能处理。
- “编辑题库”按分类题库显示目录，支持文字搜索（多个匹配题全部显示）、单题或多选删除、导出选中。
- 编辑题库支持修改题型、板块、分类题库、选项、答案、分值、解析和图片。

## 校验题库

```powershell
python validate_bank.py sample-bank.json
```

脚本检查 165 题、95/40/30 题型配比、各板块题数、分类归属、位置分值和总分 100。

## 重新生成题库

```powershell
python gen_bank.py
```

同时生成 `sample-bank.json` 和 `bank-data.js`，其中 `bank-data.js` 是页面直接使用的可编辑题库。
